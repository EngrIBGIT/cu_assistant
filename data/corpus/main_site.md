# Main site and route index

The main corporate site is a single-page application. When requested by a client
that does not execute JavaScript it returns only the shell text "You need to
enable JavaScript to run this app." and no content. The pages below were
identified through the search index rather than by direct retrieval.

## The twelve-plus property problem

The university operates at least twelve separately built web properties under
this domain, each independently branded and each publishing its own contact
details:

- www.cosmopolitan.edu.ng — main marketing site
- admission.cosmopolitan.edu.ng — admission landing page
- ug.admission.cosmopolitan.edu.ng — undergraduate application and sign-in
- pg.admission.cosmopolitan.edu.ng — postgraduate application and sign-in
- certificates.cosmopolitan.edu.ng — certificate programmes
- apply.cosmopolitan.edu.ng — IDEAS programme application and status
- student.cosmopolitan.edu.ng — student portal
- ccsa.cosmopolitan.edu.ng — Centre for Climate-Smart Agriculture
- fims.cosmopolitan.edu.ng — Farmers Information Management System
- www.films.cosmopolitan.edu.ng — Cosmopolitan Film School

No single page states which property answers which question.

## IMPORTANT — /fees/tuition exists but its content is not retrievable

A tuition fees route exists at /fees/tuition, but because the site is
client-rendered its content cannot be read from the page. **No fee figure is
therefore known to be published.** A third-party site has begun publishing
tuition figures for the university, but those are not the University's own
published figures and are not treated as one.
